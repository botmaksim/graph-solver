# OIMP_Project
=== Описание функциональности проекта ===

Приложение Graph Solver предназначено для создания, редактирования и визуализации графов.

1. Режимы работы и Конфигурация
-------------------------------
Приложение поддерживает гибкую настройку через командную строку, образуя 4 основные комбинации использования:

A. Параметры исполнения (--mode):
   - instant: Алгоритмы рассчитываются полностью за один проход.
   - step: Алгоритмы (в консольном режиме) выполняются пошагово с ожиданием подтверждения пользователя.

B. Параметры логирования (--log-target):
   - console: Вывод отладочной информации в терминал.
   - file: Запись отладочной информации в файл (требует --log-file).

2. Основные возможности (GUI)
-----------------------------
- Визуальное редактирование графов (вершины, ребра).
- Поддержка весов, цен и направленности.
- Force-Directed Layout (автоматическая укладка).
- Экспорт в PNG.

3. Алгоритмы
------------
- Поиск кратчайшего пути (Дейкстра).
- Минимальное остовное дерево (Краскал).
- Максимальный поток (Диниц).
- Минимальная стоимость потока.
- Изоморфизм (VF2).
- Раскраска (DSatur).
- Компоненты связности (Kosaraju, BFS).
- Эйлеровы циклы/пути.

4. Технические особенности
--------------------------
- Стек технологий: C++17, Qt5, CMake.
- Тестирование: Google Test.
- Логирование: spdlog (структурированный вывод).
- Архитектура: Разделение на Solvers (чистая логика) и UI. Паттерн Command для Undo/Redo.
