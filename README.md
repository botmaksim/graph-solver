# OIMP_Project
Это мой проект по ОИМП
Я планирую реализовать калькулятор для графов

Требования:
1) Ввод графа (нескольких графов) при помощи добавления вершин и ребер в графическую интерпритацию
2) Возможность редактирования графа (изменения/удаления элементов графа)
3) Возможность создания графов в разных вкладках
4) Возможность сохранения введенных графов в файл
5) Возможность загрузки ранее сохраненных файлов
6) функция поиска минимального пути между вершинами
7) функция поиска оптимального потока между вершинами
8) функция поиска максимального потока между вершинами
9) функция поиска минимального по цене потока между вершинами
10) функция нахождения изоморфизмоф
11) функция поиска слабых компонент связности
12) функция поиска сильных компонент связности
13) функция нахождения хроматического числа графа
14) функция нахождения наибольшего паросочетания в двудольном графе
15) функция проверки графа на эйлеров
