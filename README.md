# OIMP_Project
Это мой проект по ОИМП
Я планирую реализовать калькулятор для графов

Требования:
1) Ввод графа (нескольких графов) в форме матрицы связности (+ графическая интерпритация)
2) функция поиска минимального пути между вершинами
3) функция поиска оптимального потока между вершинами
4) функция поиска минимальное остовного дерева
5) функция позволяющая установить изоморфность графов
