# Graph Solver Project

Этот проект представляет собой визуализатор и решатель алгоритмов на графах, написанный на C++.

## 1. Системные требования

Перед сборкой убедитесь, что в системе установлены следующие компоненты:

*   **Операционная система:** Linux (Debian/Ubuntu/Fedora), macOS или Windows.
*   **Компилятор C++:** С поддержкой стандарта **C++17** (GCC 7+, Clang 6+, MSVC 2017+).
*   **CMake:** Версия **3.16** или новее.
*   **Qt Framework:** Версия **5** (модули `Core`, `Gui`, `Widgets`).
*   **Библиотеки:**
    *   `spdlog` (для логирования).
    *   `Google Test` (скачивается автоматически при сборке, требуется интернет).
    *   `Doxygen` (для генерации документации).

### Установка зависимостей (Debian/Ubuntu)
```bash
sudo apt update
sudo apt install build-essential cmake qtbase5-dev libspdlog-dev doxygen
```

## 2. Сборка проекта

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

## 3. Запуск и аргументы

Приложение работает в **графическом режиме (GUI)**.

### Аргументы командной строки

Приложение поддерживает аргумент для управления выводом логов:

1.  **`--log-file <path>`**:
    *   Если указан, все логи приложения (уровень INFO и выше) будут записываться в указанный файл.
    *   Если аргумент отсутствует, логи выводятся в стандартный вывод консоли (stdout).

### Примеры запуска

#### Стандартный запуск (Логи в консоль)
```bash
./GraphSolver
```

#### Запуск с сохранением логов в файл
```bash
./GraphSolver --log-file application.log
```

## 4. Тестирование

Проект использует **Google Test** для модульного тестирования. Тесты покрывают основные алгоритмы, логику графа и команды отмены/повтора.

### Запуск через CTest
После сборки проекта выполните команду в папке `build`:
```bash
ctest --output-on-failure
```

## 5. Документация

Исходный код документирован в стиле **Doxygen**. Конфигурация Doxygen интегрирована в CMake.

### Генерация документации
**Важно:** Не запускайте команду `doxygen` вручную. Используйте `make`:

```bash
make doxygen_docs
```

После завершения откройте файл `html/index.html` в браузере.
